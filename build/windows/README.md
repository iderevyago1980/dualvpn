# DualVPN — Windows

## Режимы работы

- **SOCKS5** (по умолчанию, без прав администратора): каждый туннель
  поднимает локальный SOCKS5-прокси (порты из конфига, напр. 1080/1081).
  Приложения направляют трафик через прокси вручную. wintun.dll не нужен.
- **TUN** (с правами администратора): каждый туннель создаёт свой адаптер
  Wintun (`dualvpn0`, `dualvpn1`, ...), назначает адрес/MTU и маршрутизирует
  подсети split-include. Прозрачно для всех приложений. **Требуется
  `wintun.dll` рядом с `DualVPN.exe`** и запуск от администратора.

Режим выбирается автоматически: есть админ-права → TUN, иначе SOCKS5.
Переключить вручную можно в UI (TUN недоступен без прав администратора).

## wintun.dll

Установщик кладёт `wintun.dll` рядом с `DualVPN.exe` автоматически.
При ручной сборке возьмите DLL для x64 из `build/windows/deps/wintun/bin/amd64/`
(или с https://www.wintun.net) и положите рядом с exe.

Без `wintun.dll` доступен только режим SOCKS5; попытка TUN-режима сообщит
об отсутствии драйвера.

## Установщик

`make installer` собирает `bin/DualVPN-Setup-<версия>.exe` (NSIS,
кросс-сборка на Linux). Установка per-user в `%LOCALAPPDATA%\DualVPN`,
без прав администратора; TUN-режим запрашивает повышение прав при запуске
приложения.
