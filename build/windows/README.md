# DualVPN — Windows

## wintun.dll

Для работы TUN-режима на Windows требуется драйвер Wintun.

1. Скачайте архив с официального сайта: https://www.wintun.net
2. Распакуйте и возьмите `wintun.dll` для вашей архитектуры
   (`bin/amd64/wintun.dll` для x64).
3. Поместите `wintun.dll` в эту папку — рядом с `DualVPN.exe`.

Без `wintun.dll` приложение работает только в режиме SOCKS5 (без прав
администратора); TUN-режим при запуске сообщит об отсутствии драйвера.
